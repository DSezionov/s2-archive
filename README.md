# Дос'є Зони — архів карток STALKER 2 × АТБ

Незалежний, неофіційний архів 48 колекційних карток акції STALKER 2 × АТБ:
зображення карток + два аудіозаписи на картку + текстові транскрипції.
Оригінальні QR-коди на картках більше не працюють — цей сайт відтворює той
самий контент, щоб він не зник назавжди.

## Структура

```
index.html          — головна сторінка (сітка + попап), правити НЕ треба
style.css            — стилі, правити НЕ треба (хіба що змінюєте дизайн)
script.js            — логіка сайту, правити НЕ треба
cards/
  01/
    card.webp         — зображення картки (вже є, нічого робити не треба)
    meta.json          — назва картки + категорія + назви записів  → ЗАПОВНИТИ
    text1.txt          — транскрипція запису 1                     → ЗАПОВНИТИ
    text2.txt          — транскрипція запису 2 (архів НДІЧАЗ)      → ЗАПОВНИТИ
    audio1.mp3          — файл запису 1  → ЗАВАНТАЖИТИ САМОСТІЙНО (файлу зараз немає)
    audio2.mp3          — файл запису 2  → ЗАВАНТАЖИТИ САМОСТІЙНО (файлу зараз немає)
  02/
    ...
  ...
  48/
```

Кожна з 48 папок влаштована однаково.

## Що і як заповнювати

### 1. `cards/NN/meta.json`

```json
{
  "_instructions": "...",
  "number": 1,
  "title": "TODO: назва картки",
  "category": "TODO",
  "audio1_label": "TODO: напр. Опис події",
  "audio2_label": "TODO: напр. Архів НДІЧАЗ, секція ПЗ 86-06"
}
```

- `title` — назва картки (написана на самій картці, наприклад «Перші експерименти»).
- `category` — одне з чотирьох значень, залежно від іконки на картці:
  - `event` — Подія (іконка прапорця)
  - `character` — Персонаж (іконка людини)
  - `faction` — Фракція (іконка щита)
  - `research` — Дослідження (іконка радіації)
- `audio1_label` / `audio2_label` — підпис під плеєром (наприклад «Архів НДІЧАЗ, секція ПЗ 86-06»).
- Поле `_instructions` можна просто видалити, коли заповните картку — на роботу сайту не впливає.

**Категорію не обов'язково вгадувати** — вона однозначно читається з іконки в лівому верхньому куті самої картки (`card.webp` у тій самій папці).

### 2. `cards/NN/text1.txt` та `text2.txt`

Звичайний текстовий файл. Просто відкрийте і замініть увесь вміст на текст
транскрипції. Форматування (переноси рядків) зберігається як є.

### 3. `cards/NN/audio1.mp3` та `audio2.mp3`

Цих файлів зараз **немає** в архіві — покладіть їх самостійно з такими
самими іменами. Плеєр на сайті сам "оживає": поки файлу немає — кнопка
відтворення неактивна і показано напис «файл ще не завантажено»; щойно
файл з'явиться в папці — після оновлення сторінки плеєр запрацює без
жодних правок коду.

Формат — `.mp3`. Якщо потрібен інший формат (`.ogg`, `.m4a`) — просто
поміняйте розширення у `script.js` в рядку, де формується шлях
`audio${i}.mp3` (два місця, всередині функції `openModal`).

## Публікація на GitHub Pages

1. Створіть новий репозиторій на GitHub (наприклад `dosie-zony`).
2. Завантажте туди весь вміст цієї папки (структуру не змінюйте).
3. У репозиторії: **Settings → Pages → Source → Deploy from a branch**,
   гілка `main`, папка `/ (root)`. Збережіть.
4. Через хвилину-дві сайт буде доступний за адресою
   `https://<ваш-логін>.github.io/<назва-репозиторію>/`.
5. Надалі, щоб додати аудіо чи транскрипцію — просто редагуйте/завантажуйте
   файли у відповідній папці `cards/NN/` через веб-інтерфейс GitHub або
   `git push` — Pages оновиться сам за 1-2 хвилини.

## Технічні нотатки

- Сайт повністю статичний, без сервера і без збірки — відкривається як є
  на GitHub Pages. Локально теж можна дивитись, але оскільки сторінка
  підвантажує `meta.json`/`text*.txt` через `fetch()`, при відкритті просто
  подвійним кліком на `index.html` (протокол `file://`) браузер може
  заблокувати ці запити. Для локальної перевірки запустіть простий сервер,
  наприклад: `python3 -m http.server` у цій папці, і відкрийте
  `http://localhost:8000`.
- Усі коментарі `TODO(config)` у `index.html`/`script.js` — необов'язкові
  налаштування зовнішнього вигляду (заголовок, цифри в шапці тощо), не
  плутайте їх з обов'язковим наповненням у `cards/NN/`.
